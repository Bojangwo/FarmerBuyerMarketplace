# Farmer-Buyer Marketplace 

## About the Project

The Farmer-Buyer Marketplace is a web-based platform being developed to connect farmers directly with agricultural 
buyers in The Gambia.

The aim is to make it easier for farmers to display their agricultural produce and for buyers to find available products,
compare prices, and submit purchase requests through one platform.

This project is being developed as part of my final-year Computer Science studies at the University of The Gambia.

## Problem Statement

Farmers and agricultural buyers may find it difficult to connect, share information about available produce, and negotiate 
purchases efficiently. This project aims to provide a digital platform that makes these interactions easier and more
accessible.

## Main Features

The planned features include:

* Farmer Accounts: Farmers can create accounts and manage their profiles.
* Produce Listings: Farmers can list their agricultural products with descriptions, prices, quantities, images, and locations.
* Product Search: Buyers can browse and search for available agricultural produce.
* Purchase Requests: Buyers can submit requests for products they want to purchase.
* Request Management: Farmers can view and manage purchase requests.
* Admin Dashboard: Administrators can manage platform users and monitor activities.
* Authentication and Security: User authentication and role-based access control.

*Note: The features listed above represent the planned project scope. Some features may still be under development.*
